# Changelog

## 4.0.0 — Final major release

- Replaced the default popup entry point with a Chrome side-panel workspace.
- Added an IndexedDB-backed persistent export queue and Chrome alarm recovery watchdog.
- Added pause, resume, cancel and retry job controls plus batch queueing.
- Added a ZIP64 writer with 64-bit sizes/offsets and Blob-part archive assembly in an offscreen document.
- Added CRC-32 streaming checks and bounded SHA-256 generation.
- Added download completion/interruption tracking and temporary staging cleanup.
- Added a restore centre, safe runbook and intentionally inactive adapter contract pending an official Base44 import API.
- Preserved the 3.x classic editor recovery workflow as a separate utility.
- Added Node-based syntax, smoke and ZIP64 format tests.

## 3.0.0

- Added project structure, dependency, missing-reference and configuration reports.
- Added version comparison, batch export, checksum manifests and repository documentation.

## 2.5.0

- Initial project export and editor recovery baseline.
