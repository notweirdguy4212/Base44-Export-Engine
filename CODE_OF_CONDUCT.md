# Code of Conduct

We want participation in this project to be welcoming and constructive.

- Be respectful and assume good intent.
- Give actionable feedback about code and ideas, not personal attacks.
- Welcome different experience levels and communication styles.
- Do not publish credentials, private project content or personal data.
- Maintainers may edit or remove content that is abusive, discriminatory, threatening or exposes private information.

For serious or repeated concerns, contact the project maintainer privately.
