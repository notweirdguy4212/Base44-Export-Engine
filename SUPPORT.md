# Support

Before asking for help:

1. Check the installation and limitations sections in `README.md`.
2. Reload the unpacked extension and the Base44 project tab.
3. Run **Connection diagnostics** and note the non-sensitive results.
4. Try a small path list to determine whether direct export or editor recovery is failing.

When reporting a problem, include the Toolkit version, Chrome version, relevant error text and whether the file tree/editor was visible. Redact project identifiers if they are sensitive. Never share access tokens, cookies or private source files.
