# VS Code Android Pro — Deutsch

Eine von VS Code inspirierte Android-Programmierumgebung.

Dies ist eine native Android-Grundlage, keine offizielle Microsoft-App und kein vollständiger Code-OSS-Port.

## Status
Diese Ausgabe beschreibt den Starter 0.2.0. Die App ist noch keine vollständige mobile Implementierung des Desktop-Editors.

## Aktuelle Funktionen
Compose-Oberfläche, Tabs im Arbeitsspeicher, Öffnen und Speichern über Android-Dokumentauswahl, Suchen und Ersetzen, Sprachmodus-Auswahl sowie UI-Bereiche für Terminal, Ausgabe, Probleme und Debugging.

**Belangrijk:** taalmodi zijn alleen labels en extensieherkenning. Ze betekenen niet dat syntaxiskleuring, IntelliSense, compiler, runtime of debugger beschikbaar is.

## Build
Öffne das Stammverzeichnis in Android Studio. Verwende JDK 17, Android SDK 35 und Android Gradle Plugin 8.9.2. Synchronisiere Gradle und starte app auf einem Android-Gerät oder Emulator ab API 26.
