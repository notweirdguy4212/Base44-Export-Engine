# VS Code Android Pro — Italiano

Un ambiente di programmazione Android ispirato a VS Code.

Questa è una base Android nativa non ufficiale, non un port completo di Code-OSS.

## Stato
Questa edizione descrive la versione iniziale 0.2.0. L'app non è ancora un'implementazione mobile completa dell'editor desktop.

## Funzioni attuali
Interfaccia Compose, schede in memoria, apertura e salvataggio tramite selettore documenti Android, ricerca e sostituzione, selettore della modalità linguaggio e pannelli UI per terminale, output, problemi e debug.

**Belangrijk:** taalmodi zijn alleen labels en extensieherkenning. Ze betekenen niet dat syntaxiskleuring, IntelliSense, compiler, runtime of debugger beschikbaar is.

## Compilazione
Apri la cartella principale in Android Studio. Usa JDK 17, Android SDK 35 e Android Gradle Plugin 8.9.2. Sincronizza Gradle ed esegui app su un dispositivo o emulatore Android API 26 o successivo.
