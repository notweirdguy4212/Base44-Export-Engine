# VS Code Android Pro — Bahasa Indonesia

Ruang kerja coding Android yang terinspirasi oleh VS Code.

Ini adalah fondasi Android native independen, bukan aplikasi resmi Microsoft atau port Code-OSS lengkap.

## Status
Edisi ini menjelaskan starter versi 0.2.0. Aplikasi ini belum merupakan implementasi seluler lengkap dari editor desktop.

## Fitur saat ini
UI Compose, tab dalam memori, buka dan simpan melalui pemilih dokumen Android, cari/ganti, pemilih mode bahasa, serta panel UI terminal, output, masalah, dan debug.

**Belangrijk:** taalmodi zijn alleen labels en extensieherkenning. Ze betekenen niet dat syntaxiskleuring, IntelliSense, compiler, runtime of debugger beschikbaar is.

## Build dan jalankan
Buka folder root proyek di Android Studio. Gunakan JDK 17, Android SDK 35, dan Android Gradle Plugin 8.9.2. Setelah Gradle sync, jalankan app pada perangkat atau emulator Android API 26 ke atas.

## Sumber upstream dan lisensi
Kode sumber Code-OSS yang diberikan adalah proyek desktop berbasis Electron. Lisensi MIT tersedia di licenses/CODE_OSS_LICENSE.txt. Daftar Awesome VS Code berlisensi CC0 1.0 di licenses/AWESOME_VSCODE_CC0.txt. Seluruh sumber desktop dan ekstensinya tidak disertakan ke dalam aplikasi ini.

## Peta jalan
Lihat docs/ROADMAP.md untuk rencana integrasi mesin editor, workspace, server bahasa, eksekusi sandbox, Git, dan debugging. Fitur tersebut belum dinyatakan selesai.

## Merek dagang
VS Code dan Visual Studio Code adalah merek dagang Microsoft. Proyek komunitas independen ini tidak didukung atau disponsori Microsoft.
