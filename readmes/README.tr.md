# VS Code Android Pro — Türkçe

VS Code'dan ilham alan Android kodlama çalışma alanı.

Bu, bağımsız bir yerel Android temelidir; Microsoft'un resmî uygulaması veya Code-OSS'un tam bağlantı noktası değildir.

## Durum
Bu sürüm 0.2.0 başlangıç paketini açıklar. Uygulama henüz masaüstü düzenleyicinin tam bir mobil uygulaması değildir.

## Mevcut özellikler
Compose arayüzü, bellekte sekmeler, Android belge seçiciyle dosya açma/kaydetme, bul/değiştir, dil modu seçimi ve terminal, çıktı, sorunlar ve hata ayıklama paneli arayüzleri bulunur.

**Belangrijk:** taalmodi zijn alleen labels en extensieherkenning. Ze betekenen niet dat syntaxiskleuring, IntelliSense, compiler, runtime of debugger beschikbaar is.

## Derleme ve çalıştırma
Proje kök klasörünü Android Studio'da açın. JDK 17, Android SDK 35 ve Android Gradle Plugin 8.9.2 gerekir. Gradle eşitlemesinden sonra app yapılandırmasını API 26 veya üzeri Android cihazda ya da emülatörde çalıştırın.

## Kaynaklar ve lisanslar
Sağlanan Code-OSS kaynak kodu Electron tabanlı bir masaüstü projesidir. MIT lisansı licenses/CODE_OSS_LICENSE.txt dosyasındadır. Awesome VS Code listesi CC0 1.0 lisanslıdır; licenses/AWESOME_VSCODE_CC0.txt dosyasına bakın. Tam masaüstü kaynak kodu ve uzantıları bu uygulamaya eklenmemiştir.

## Yol haritası
Editör motoru, çalışma alanları, dil sunucuları, yalıtılmış çalıştırma, Git ve hata ayıklama planları için docs/ROADMAP.md dosyasına bakın. Bunlar henüz uygulanmış değildir.

## Markalar
VS Code ve Visual Studio Code, Microsoft'un ticari markalarıdır. Bu bağımsız topluluk projesi Microsoft tarafından onaylanmamıştır.
