# VS Code Android Pro — हिन्दी

VS Code से प्रेरित Android कोडिंग वर्कस्पेस।

यह स्वतंत्र Android नेटिव आधार परियोजना है, Microsoft का आधिकारिक ऐप या Code-OSS का पूर्ण पोर्ट नहीं।

## वर्तमान स्थिति
यह संस्करण 0.2.0 स्टार्टर का वर्णन करता है। ऐप अभी डेस्कटॉप एडिटर का पूर्ण मोबाइल संस्करण नहीं है।

## मौजूदा सुविधाएँ
Compose UI, मेमोरी टैब, Android दस्तावेज़ चयनकर्ता से फ़ाइल खोलना और सहेजना, खोज/बदलना, भाषा मोड चयन और टर्मिनल, आउटपुट, समस्याओं तथा डीबग पैनल के UI शामिल हैं।

**Belangrijk:** taalmodi zijn alleen labels en extensieherkenning. Ze betekenen niet dat syntaxiskleuring, IntelliSense, compiler, runtime of debugger beschikbaar is.

## बिल्ड और चलाएँ
Android Studio में प्रोजेक्ट का मूल फ़ोल्डर खोलें। JDK 17, Android SDK 35 और Android Gradle Plugin 8.9.2 चाहिए। Gradle sync के बाद API 26 या नए Android डिवाइस/एम्युलेटर पर app चलाएँ।

## अपस्ट्रीम स्रोत और लाइसेंस
दिया गया Code-OSS स्रोत Electron-आधारित डेस्कटॉप प्रोजेक्ट है। MIT लाइसेंस licenses/CODE_OSS_LICENSE.txt में है। Awesome VS Code सूची CC0 1.0 के अंतर्गत है; licenses/AWESOME_VSCODE_CC0.txt देखें। पूरा डेस्कटॉप स्रोत और उसके एक्सटेंशन इस ऐप में शामिल नहीं हैं।

## विकास रोडमैप
एडिटर इंजन, वर्कस्पेस, भाषा सर्वर, सैंडबॉक्स रनटाइम, Git और डीबगिंग की भविष्य की योजना के लिए docs/ROADMAP.md देखें। ये सुविधाएँ अभी लागू नहीं हैं।

## ट्रेडमार्क
VS Code और Visual Studio Code Microsoft के ट्रेडमार्क हैं। यह स्वतंत्र सामुदायिक परियोजना है और Microsoft द्वारा समर्थित नहीं है।
