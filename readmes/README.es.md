# VS Code Android Pro — Español

Un entorno de programación Android inspirado en VS Code.

Esta es una base nativa para Android, no una versión oficial de Microsoft ni una adaptación completa de Code-OSS.

## Estado
Esta edición documenta la versión inicial 0.2.0. La aplicación todavía no es una implementación móvil completa del editor de escritorio.

## Funciones actuales
Interfaz Compose, pestañas en memoria, apertura y guardado mediante el selector de documentos de Android, búsqueda y reemplazo, selector de modo de lenguaje y paneles de interfaz para terminal, salida, problemas y depuración.

**Belangrijk:** taalmodi zijn alleen labels en extensieherkenning. Ze betekenen niet dat syntaxiskleuring, IntelliSense, compiler, runtime of debugger beschikbaar is.

## Compilación
Abre la carpeta raíz en Android Studio. Usa JDK 17, Android SDK 35 y Android Gradle Plugin 8.9.2. Sincroniza Gradle y ejecuta la configuración app en un dispositivo o emulador Android API 26 o posterior.
