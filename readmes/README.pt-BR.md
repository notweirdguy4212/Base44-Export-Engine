# VS Code Android Pro — Português (Brasil)

Um ambiente de programação Android inspirado no VS Code.

Esta é uma base Android nativa e não oficial, não uma versão completa do Code-OSS.

## Status
Esta edição descreve a versão inicial 0.2.0. O aplicativo ainda não é uma implementação móvel completa do editor desktop.

## Recursos atuais
Interface Compose, abas em memória, abrir e salvar pelo seletor de documentos do Android, localizar e substituir, seletor de modo de linguagem e painéis de interface para terminal, saída, problemas e depuração.

**Belangrijk:** taalmodi zijn alleen labels en extensieherkenning. Ze betekenen niet dat syntaxiskleuring, IntelliSense, compiler, runtime of debugger beschikbaar is.

## Compilação
Abra a pasta raiz no Android Studio. Use JDK 17, Android SDK 35 e Android Gradle Plugin 8.9.2. Sincronize o Gradle e execute app em um dispositivo ou emulador Android API 26 ou superior.
