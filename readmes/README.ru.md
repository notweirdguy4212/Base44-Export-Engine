# VS Code Android Pro — Русский

Среда программирования для Android по мотивам VS Code.

Это независимая нативная основа для Android, а не официальный продукт Microsoft и не полный порт Code-OSS.

## Состояние
В этой редакции описана стартовая версия 0.2.0. Приложение пока не является полной мобильной реализацией настольного редактора.

## Текущие возможности
Интерфейс Compose, вкладки в памяти, открытие и сохранение через системный выбор документов Android, поиск и замена, выбор языкового режима и панели интерфейса терминала, вывода, проблем и отладки.

**Belangrijk:** taalmodi zijn alleen labels en extensieherkenning. Ze betekenen niet dat syntaxiskleuring, IntelliSense, compiler, runtime of debugger beschikbaar is.

## Сборка
Откройте корневую папку в Android Studio. Используйте JDK 17, Android SDK 35 и Android Gradle Plugin 8.9.2. Синхронизируйте Gradle и запустите app на устройстве или эмуляторе Android API 26+.

## Исходные материалы и лицензии
Предоставленный исходный код Code-OSS — настольный проект на Electron. Лицензия MIT находится в licenses/CODE_OSS_LICENSE.txt. Список Awesome VS Code распространяется по CC0 1.0: licenses/AWESOME_VSCODE_CC0.txt. Полный настольный исходный код и расширения не встроены в приложение.
