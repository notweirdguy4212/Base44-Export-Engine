# VS Code Android Pro — Nederlands

Een Android-codeerwerkruimte geïnspireerd op VS Code.

Dit is een onafhankelijke native Android-basis, geen officiële Microsoft-app en geen volledige Code-OSS-port.

## Status
Deze editie beschrijft starterversie 0.2.0. De app is nog geen volledige mobiele implementatie van de desktopeditor.

## Huidige functies
Compose-interface, tabbladen in geheugen, bestanden openen en opslaan via de Android-documentkiezer, zoeken en vervangen, taalmodusselectie en UI-panelen voor terminal, uitvoer, problemen en debuggen.

**Belangrijk:** taalmodi zijn alleen labels en extensieherkenning. Ze betekenen niet dat syntaxiskleuring, IntelliSense, compiler, runtime of debugger beschikbaar is.

## Bouwen en uitvoeren
Open de hoofdmap in Android Studio. Gebruik JDK 17, Android SDK 35 en Android Gradle Plugin 8.9.2. Synchroniseer Gradle en start app op een Android-apparaat of emulator met API 26 of hoger.

## Bronmateriaal en licenties
De aangeleverde Code-OSS-broncode is een Electron-desktopproject. De MIT-licentie staat in licenses/CODE_OSS_LICENSE.txt. De Awesome VS Code-lijst valt onder CC0 1.0 in licenses/AWESOME_VSCODE_CC0.txt. De volledige desktopbroncode en extensies zijn niet in deze app opgenomen.

Zie docs/ROADMAP.md voor toekomstige integratie van een editor-engine, workspaces, language servers, sandbox-uitvoering, Git en debuggen. Deze functies zijn nog niet als voltooid gemarkeerd.
