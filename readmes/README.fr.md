# VS Code Android Pro — Français

Un environnement de programmation Android inspiré de VS Code.

Il s'agit d'une base Android native, non officielle et non équivalente à une adaptation complète de Code-OSS.

## État
Cette édition décrit la version de base 0.2.0. L’application n’est pas encore une implémentation mobile complète de l’éditeur de bureau.

## Fonctions actuelles
Interface Compose, onglets en mémoire, ouverture et enregistrement via le sélecteur de documents Android, recherche et remplacement, choix du mode de langage et panneaux d’interface pour terminal, sortie, problèmes et débogage.

**Belangrijk:** taalmodi zijn alleen labels en extensieherkenning. Ze betekenen niet dat syntaxiskleuring, IntelliSense, compiler, runtime of debugger beschikbaar is.

## Compilation
Ouvrez le dossier racine dans Android Studio. Utilisez JDK 17, Android SDK 35 et Android Gradle Plugin 8.9.2. Synchronisez Gradle puis lancez la configuration app sur un appareil ou émulateur Android API 26 ou ultérieur.
