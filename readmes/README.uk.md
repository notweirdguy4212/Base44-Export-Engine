# VS Code Android Pro — Українська

Середовище програмування Android, натхненне VS Code.

Це незалежна нативна основа для Android, а не офіційний продукт Microsoft чи повний порт Code-OSS.

## Стан
Ця редакція описує початкову версію 0.2.0. Застосунок ще не є повною мобільною реалізацією настільного редактора.

## Поточні можливості
Інтерфейс Compose, вкладки в пам’яті, відкриття та збереження через системний вибір документів Android, пошук і заміна, вибір мовного режиму та панелі інтерфейсу термінала, виводу, проблем і налагодження.

**Belangrijk:** taalmodi zijn alleen labels en extensieherkenning. Ze betekenen niet dat syntaxiskleuring, IntelliSense, compiler, runtime of debugger beschikbaar is.

## Збирання
Відкрийте кореневу теку в Android Studio. Використовуйте JDK 17, Android SDK 35 та Android Gradle Plugin 8.9.2. Синхронізуйте Gradle і запустіть app на пристрої або емуляторі Android API 26+.
