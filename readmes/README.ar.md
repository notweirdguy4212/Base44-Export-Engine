# VS Code Android Pro — العربية

بيئة برمجة لنظام Android مستوحاة من VS Code.

هذا مشروع أساس مستقل أصلي لنظام Android، وليس تطبيقاً رسمياً من Microsoft ولا نقلاً كاملاً لـ Code-OSS.

## الحالة الحالية
تصف هذه النسخة الإصدار التمهيدي 0.2.0. التطبيق ليس بعد تنفيذاً كاملاً لمحرر سطح المكتب على الهاتف.

## الميزات المنفذة حالياً
واجهة Compose، وعلامات تبويب في الذاكرة، وفتح الملفات وحفظها عبر منتقي مستندات Android، والبحث والاستبدال، واختيار وضع اللغة، وواجهات لوحات الطرفية والمخرجات والمشكلات وتصحيح الأخطاء.

**Belangrijk:** taalmodi zijn alleen labels en extensieherkenning. Ze betekenen niet dat syntaxiskleuring, IntelliSense, compiler, runtime of debugger beschikbaar is.

## البناء والتشغيل
افتح مجلد المشروع الرئيسي في Android Studio. يلزم JDK 17 وAndroid SDK 35 وAndroid Gradle Plugin 8.9.2. بعد مزامنة Gradle شغّل app على جهاز أو محاكي Android بإصدار API 26 أو أحدث.

## المصادر والتراخيص
مصدر Code-OSS المرفق مشروع سطح مكتب يعتمد على Electron. نص ترخيص MIT موجود في licenses/CODE_OSS_LICENSE.txt. قائمة Awesome VS Code مرخصة وفق CC0 1.0 في licenses/AWESOME_VSCODE_CC0.txt. لم يتم تضمين مصدر سطح المكتب الكامل أو إضافاته في هذا التطبيق.

## خارطة الطريق
راجع docs/ROADMAP.md لمعرفة الخطط المستقبلية لمحرك التحرير ومساحات العمل وخوادم اللغات والتنفيذ المعزول وGit وتصحيح الأخطاء. هذه الميزات غير مكتملة حالياً.

## العلامات التجارية
VS Code وVisual Studio Code علامتان تجاريتان لشركة Microsoft. هذا مشروع مجتمعي مستقل وغير معتمد من Microsoft.
